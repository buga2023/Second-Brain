# Glossário

Siglas, termos internos e codinomes, decodificados uma vez para não
precisar perguntar de novo.

| Termo | Significado |
|---|---|
| GP | GP Consultoria e Engenharia |
| V.L.A.E.G. | Framework de planejamento usado nos pacotes de automação (`vlaeg-framework`) |
| NTI | Setor de TI dentro da GP; mesmo ambiente e mesmos sistemas |
| FD | Folha de dados (documento de engenharia gerado a partir de modelo) |
| Barra | Referência concreta contra a qual um crítico dá veredito binário |
| Check vermelho | Verificação que falha antes do trabalho e só passa quando ele está feito |
| Portão | Checagem que bloqueia a passagem para a próxima etapa; humano quando só uma pessoa pode conferir |
| Teto | Limite de voltas, tempo ou custo de um loop; bater nele é falha a relatar |
| Fronteira (frontier) | Decisões que já dá para perguntar agora, porque o que vem antes está resolvido |
| V.I.B.E. | Visão-Express, Implementa, Blinda, Escala: protocolo de vibecoding para MVP ([vibecode-flow](projects/vibecode-flow.md)) |
| Esteira NTI | Ciclo de evolução contínua de agentes de IA em produção, do NTI ([esteira-nti](../wiki/projetos/esteira-nti.md)) |
| RHAWK | rhawk.pro, autora dos slides do ciclo de evolução orientado a negócio ([rhawk](../wiki/entidades/rhawk.md)) |
| Harness | Tudo em volta do modelo: prompt, ferramentas, regras, middleware ([harness](../wiki/conceitos/harness.md)) |
| Self-Harness | Agente que reescreve o próprio harness: garimpo → proposta → validação ([self-harness](../wiki/conceitos/self-harness.md)) |
| Grilling | Entrevista em rodadas sobre as decisões em aberto antes de construir (skill `grilling`, Matt Pocock) ([nota](context/entrevista-antes-do-grafo.md)) |
| Wayfinder | Mapa de tickets de decisão para trabalho maior que uma sessão (Matt Pocock) |
| Gauntlet loop | Loop de validação de planos citado nos vídeos Maestros da IA; usar só depois do grilling |
| Graph engineering | Desenho de grafos de execução de agentes ([skill](../skills/graph-engineering/SKILL.md)) |
