# prompt-engineering

Skill do usuário (`anthropic-skills:prompt-engineering`, pacote
`prompt-engineering-v1.zip`). Refina prompts com as boas práticas da
Anthropic: clareza, exemplos, chain-of-thought, tags XML, papel,
estrutura em camadas e prefill. Fluxo: diagnosticar → reescrever →
mostrar antes/depois. A referência `techniques.md` traz as técnicas.
