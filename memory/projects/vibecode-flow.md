# vibecode-flow

Skill do usuário (`anthropic-skills:vibecode-flow`, pacote
`vibecode-flow-v1.zip`). Aplica o **Protocolo V.I.B.E.**: Visão-Express,
Implementa, Blinda, Escala. É "vibecoding estruturado" para MVP, protótipo,
prova de conceito e side project.

- Referências por fase (`fase_v`, `fase_i`, `fase_b`, `fase_e`), stacks,
  ferramentas de IA e templates (`.env.example`, smoke test, Sentry).
- `references/migration_vlaeg.md` diz quando o MVP deixa de ser vibecode
  e passa para o **V.L.A.E.G.** (`vlaeg-framework`), o framework das
  automações de produção.
